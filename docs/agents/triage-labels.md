# Triage Labels

ใช้ default label vocabulary ของ engineering skills สำหรับ local issue tracker

| Canonical role | Label ใน tracker | ความหมาย |
|---|---|---|
| `needs-triage` | `needs-triage` | ต้องประเมิน issue |
| `needs-info` | `needs-info` | ต้องการข้อมูลเพิ่ม |
| `ready-for-agent` | `ready-for-agent` | Spec พร้อมสำหรับ agent นำไป implementation |
| `ready-for-human` | `ready-for-human` | ต้องให้มนุษย์ดำเนินการ |
| `wontfix` | `wontfix` | ไม่ดำเนินการ |

ใช้ `Status: ready-for-agent` สำหรับ spec ที่เผยแพร่ ไม่เพิ่ม triage รอบใหม่
